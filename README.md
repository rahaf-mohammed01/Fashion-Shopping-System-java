# Fashion Shopping System

A cross-platform fashion shopping system built using Java (OOP) and Swift, allowing users to create accounts, browse products, add items to their cart, and complete purchases through a user-friendly interface.

---

##  Overview
GlowUP is a simulated clothing company system that demonstrates object-oriented programming (OOP) concepts and GUI development. The project models real-world business operations such as customer management, product handling, ordering, and payment processing.

It also includes a graphical user interface (GUI) where users can interact with the system by creating accounts and purchasing products.

---

## Target Audience
- General users interested in online shopping  
- Anyone who wants to buy clothes through a simple and interactive system  

---

## Project Idea
The project represents a clothing company called **GlowUP**, where:
- Customers can create accounts  
- Browse available clothing items  
- Add products to their shopping bag  
- Proceed to checkout and complete payments  

---

## Features
- Account creation system  
- Product browsing and display  
- Shopping bag (cart) functionality  
- Checkout system with payment options  
- User-friendly GUI  
- Simulation of real company operations  

---

## System Functionality
The system is built using multiple classes to simulate a real business environment:

- **Company & Administration** → Manage company operations  
- **Employee** → Represents staff members  
- **Customer** → Stores user data and interactions  
- **Clothes** → Represents products  
- **Order** → Handles purchases and transactions  
- **PaymentMethod** → Supports different payment types (cash, card)  
- **Service & Shipping** → Manage delivery and services  
- **Online / Shop** → Represents the shopping system  

---

##  Technologies Used

## GUI Features (GlowupApp)
The application includes:

- **Create Account Page**
  - User input validation  
  - Account setup  

- **Product Page**
  - Display available clothing items  
  - Select quantity  

- **Shopping Bag**
  - Add/remove items  
  - View selected products  

- **Checkout Page**
  - Choose payment method  
  - Complete purchase
